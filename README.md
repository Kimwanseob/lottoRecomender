# 로또 6/45 덜 나온 번호 추첨기

동행복권(dhlottery.co.kr) 제1회부터 최신 회차까지의 당첨번호를 분석해,
역대 가장 적게 나온 번호를 기반으로 6개 번호를 뽑아 주는 추첨기입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 추첨기 본체 (단일 파일, 브라우저만 있으면 어디서든 동작) |
| `update-data.mjs` | 당첨번호 데이터 갱신 스크립트 (Node.js 18+) |
| `data/draws.json` | 회차별 당첨번호 캐시 |
| `vendor/jsqr.min.js` | QR 디코더 폴백 (jsQR, Apache-2.0) — 스캔할 때만 지연 로드 |

## 사용법

- **웹 (모바일·윈도우·맥)**: https://niceguykws.github.io/lottoRecomender/
- **로컬**: `index.html`을 더블클릭해 브라우저로 열면 됩니다.

### 추첨 방식 4가지

1. **덜 나온 가중** — 출현 횟수가 적은 번호일수록 뽑힐 확률이 높아짐 (기본)
2. **최소 TOP 15** — 역대 최소 출현 15개 번호 안에서만 추첨
3. **비인기 조합** — 회차별 등수별 당첨자 수·판매액으로 학습한 선형회귀 모델로
   사람들이 잘 안 고르는 조합을 추천 (당첨 확률은 같지만, 1등 시 나눠 갖는 인원 최소화)
4. **완전 랜덤** — 1–45 균등 추첨

통계 카드로 역대 최소/최대 출현 TOP 10과 번호별 출현 횟수 차트를 제공하며,
UI는 동행복권 공식 사이트의 디자인 토큰(볼 색상·컬러)을 따랐습니다.

## 내 로또 확인 (QR 스캔 · 자동 대조)

구매한 용지의 QR을 스캔해 두면, 페이지를 열 때마다 저장된 번호를 최신 당첨번호와
자동으로 대조합니다.

- **QR 스캔** — 카메라로 용지 아래쪽 QR을 읽습니다. `BarcodeDetector`를 지원하는
  브라우저에서는 네이티브 디코더를, 그 외(사파리 등)에서는 `vendor/jsqr.min.js`를
  지연 로드해 사용합니다. 카메라는 https 주소에서만 열립니다.
- **사진에서 찾기** — 찍어 둔 사진에서 QR을 찾습니다. 카메라 권한이 없을 때 쓰세요.
- **직접 입력** — 회차와 번호를 한 줄에 6개씩 입력합니다.

QR에 회차가 들어 있어 스캔 즉시 회차 상태를 배지로 보여 줍니다.

| 배지 | 조건 | 표시 |
|---|---|---|
| 이번 회차 · 추첨 완료 | 저장 회차 = 최신 회차 | 게임별 등수 |
| 추첨 대기 | 저장 회차 > 최신 회차 | `대기` |
| 지난 회차 | 저장 회차 < 최신 회차 | `data/draws.json`을 불러와 등수 판정 |

용지는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다. 같은 QR을
다시 읽으면 중복 저장되지 않습니다. 등수는 6개 일치 1등, 5개+보너스 2등, 5개 3등,
4개 4등, 3개 5등 기준입니다.

### QR 형식

동행복권 용지 QR은 아래와 같은 URL 한 줄입니다.

```
https://m.dhlottery.co.kr/qr.do?method=winQr&v=1131m121528363940m020825363942m...
                                                ^^^^ 회차  ^구분자 ^^^^^^^^^^^^ 번호 6개
```

`4자리 회차` 뒤에 `구분자 1글자(q 자동 · m 수동 등) + 두 자리씩 번호 6개`가 게임 수만큼
반복되고, 그 뒤 꼬리값은 무시합니다.

## 데이터 갱신 (매주 토요일 추첨 후)

조회 범위는 **제1회(고정) ~ 최신 회차**이며, 최신 회차는 동행복권 서버에서
자동으로 감지해 조회 조건에 채웁니다. 이미 받아 둔 회차는 건너뛰고
새 회차만 내려받아 `index.html`의 데이터 구간을 자동으로 갱신합니다.

```
node update-data.mjs
```

## 참고

- QR 스캔 결과는 참고용입니다. 당첨금 수령에는 실물 용지가 필요하며, 최종 확인은
  동행복권 공식 채널에서 하세요.
- 통계는 본번호(6개) 기준이며 보너스 번호는 출현 횟수에 포함하지 않습니다.
- 매 회차 추첨은 독립 시행이므로 과거에 덜 나온 번호가 앞으로 더 잘 나올
  통계적 근거는 없습니다. 재미로만 활용하세요.
